# EvandroRipka.dev

A premium portfolio experience built to showcase my work as a software engineer, product builder, and interactive experience creator.

## Overview

EvandroRipka.dev is my personal portfolio and creative engineering platform.

This project is designed to combine strong visual direction, immersive interaction, and real-world product thinking in a single experience. The goal is to present selected projects, technical depth, creative identity, and business-oriented execution in a way that feels premium, memorable, and internationally competitive.

## Vision

This portfolio follows a hybrid structure:

- **Professional core** focused on clarity, credibility, and conversion
- **Immersive layer** to highlight creative and technical range
- **Dedicated full interactive experience** to showcase a more experimental and cinematic direction

This approach is intended to balance design impact with professional usability.

## Main Goals

- Build an award-worthy portfolio experience
- Strengthen my international-facing personal brand
- Present selected projects with more authority and narrative
- Support long-term positioning for clients, partnerships, and global opportunities
- Create a portfolio that reflects both technical and creative depth

## Featured Projects

- **Eu Quero Milhas** — Laravel marketplace for buying and selling miles and flight opportunities
- **Pressplay LMS** — WordPress + WooCommerce LMS product
- **Assina Jogos** — custom digital game rental and subscription platform
- **Assembly Internal Systems** — institutional software for access control, events, file management, and transparency-related improvements
- **Sleepy Hollow** — narrative open-world horror project built in Unreal Engine 5.4
