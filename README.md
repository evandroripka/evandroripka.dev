## Overview

EvandroRipka.dev is a personal portfolio and creative engineering platform designed to combine strong visual direction, immersive interaction, and real-world product thinking in a single experience.

The goal is to present selected projects, technical depth, creative identity, and business-oriented execution in a way that feels premium, memorable, and internationally competitive.

## Experience Vision

This portfolio follows a hybrid structure:

| Layer | Focus |
| --- | --- |
| Professional Core | Clarity, credibility, and conversion |
| Immersive Layer | Creative and technical range |
| Interactive Experience | Experimental and cinematic storytelling |

This approach is intended to balance design impact with professional usability.

## Main Goals

- Build an award-worthy portfolio experience
- Strengthen my international-facing personal brand
- Present selected projects with more authority and narrative
- Support long-term positioning for clients, partnerships, and global opportunities
- Create a portfolio that reflects both technical and creative depth

## Local Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Expose the development server externally when needed:

```bash
npm run dev -- --host 0.0.0.0
```

## Git Workflow

- `main` -> stable branch
- `staging` -> active development branch

New work is developed and validated in `staging`, then promoted to `main` when ready.
